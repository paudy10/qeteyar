# قطعه‌یار — سامانه انبارداری قطعات موبایل (نسخه ۱.۱)

برنامه تحت وب فارسی و راست‌چین برای مدیریت موجودی قطعات تعمیرات موبایل؛ با HTML، CSS، JavaScript، Node.js و پایگاه‌داده SQLite داخلی Node.js. این بسته، نسخه ۱.۱ را با Docker و Docker Compose اجرا می‌کند و نیاز به نصب پکیج‌های npm ندارد.

## امکانات نسخه ۱.۱

- تعریف محصول انباری با نام، مدل، دسته‌بندی، برند، قیمت پایه به ریال، معادل دلاری، موجودی و حد هشدار.
- دسته‌بندی‌های پیش‌فرض: ال‌سی‌دی، درب پشت، سوکت شارژ، میکروفون، باتری، دوربین، فلت و کابل، اسپیکر و سایر.
- برندهای پیش‌فرض: سامسونگ، آیفون، هواوی و شیائومی؛ امکان افزودن برند و دسته جدید.
- ثبت شارژ انبار و ثبت فروش/مصرف موجودی همراه نام تعمیرکار؛ جلوگیری از خروج بیش از موجودی.
- ثبت تأمین و مصرف مستقیم با قیمت خرید و قیمت زمان استفاده/فروش، نام تعمیرکار و قطعه‌فروش، بدون دستکاری موجودی انبار.
- نرخ دلار از PriceToDay با کش ۵ دقیقه‌ای و نگهداری آخرین نرخ موفق هنگام قطع سرویس.
- صفحه مستقل جست‌وجوی محصول و نمایش ارزش ریالی بر اساس نرخ دلار در دسترس.
- گزارش با تاریخ شمسی و فیلترهای ترکیبی نوع عملیات، تعمیرکار، برند، دسته‌بندی و قطعه‌فروش/تأمین‌کننده.
- چاپ گزارش و ذخیره PDF از مرورگر؛ چیدمان گزارش برای چاپ افقی A4.
- ورود مدیر، هش رمز عبور، کوکی نشست HttpOnly و محدودیت تلاش ناموفق ورود.

## اجرای برنامه با Docker

### پیش‌نیاز

- نصب Docker Desktop در ویندوز (با Docker Compose) یا Docker Engine و Docker Compose در لینوکس.
- هنگام استفاده از Docker Desktop، مطمئن شوید Docker در حال اجراست.

### مراحل اجرا

۱. فایل ZIP را استخراج کنید و وارد پوشه `ghateh-yar` شوید؛ همان پوشه‌ای که `Dockerfile` و `docker-compose.yml` داخل آن قرار دارند.

۲. از فایل تنظیمات نمونه یک فایل `.env` بسازید.

در Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

در Linux/macOS:

```bash
cp .env.example .env
```

۳. فایل `.env` را باز کنید. پیش از اولین اجرا، `ADMIN_USER` و `ADMIN_PASSWORD` را به نام کاربری و رمز دلخواه تغییر دهید. برای استفاده واقعی، رمز پیش‌فرض را نگه ندارید.

۴. در همان پوشه اجرا کنید:

```bash
docker compose up -d --build
```

۵. در مرورگر باز کنید:

<http://localhost:3000>

اگر `APP_PORT` را در `.env` به عدد دیگری تغییر داده‌اید، همان پورت را در آدرس مرورگر وارد کنید.

## فرمان‌های رایج Docker

مشاهده وضعیت کانتینر:

```bash
docker compose ps
```

مشاهده لاگ‌های سرور:

```bash
docker compose logs -f ghateh-yar
```

توقف برنامه بدون حذف اطلاعات:

```bash
docker compose down
```

اجرای دوباره:

```bash
docker compose up -d
```

بازسازی تصویر پس از تغییر فایل‌های برنامه:

```bash
docker compose up -d --build
```

## پایگاه‌داده و حفظ اطلاعات قبلی

پایگاه‌داده داخل پوشه `data/inventory.sqlite` ذخیره می‌شود و در Docker از طریق bind mount به `/app/data` وصل است؛ بنابراین با `docker compose down` حذف نمی‌شود. فایل‌های واقعی پایگاه‌داده داخل ZIP قرار ندارند.

اگر داده‌های نسخه ۱.۱ را می‌خواهید نگه دارید:

1. برنامه محلی قدیمی را به‌طور کامل متوقف کنید.
2. فایل `data/inventory.sqlite` نسخه قبلی را در پوشه `data` همین پروژه قرار دهید. اگر فایل‌های `inventory.sqlite-wal` یا `inventory.sqlite-shm` هم باقی مانده‌اند، تنها پس از خاموش شدن کامل برنامه و طبق روال امن پشتیبان‌گیری SQLite اقدام کنید؛ صرفاً فایل فعال پایگاه‌داده را از برنامه در حال اجرا کپی نکنید.
3. سپس `docker compose up -d --build` را اجرا کنید.

از `data/inventory.sqlite` مرتب نسخه پشتیبان تهیه کنید. فرمان `docker compose down` اطلاعات پوشه `data` را پاک نمی‌کند؛ با این حال پوشه را از فایل‌های برنامه حذف نکنید.

اگر در Linux با خطای دسترسی نوشتن داخل `data` روبه‌رو شدید، مجوز مالکیت پوشه را برای کاربر داخل تصویر Docker (UID 1000) تنظیم کنید:

```bash
sudo chown -R 1000:1000 data
```

## نام کاربری و رمز عبور

مقادیر `ADMIN_USER` و `ADMIN_PASSWORD` در `.env` فقط برای ایجاد حساب اولیه استفاده می‌شوند. رمز کاربر در SQLite به‌صورت هش‌شده نگه‌داری می‌شود؛ بنابراین تغییر `.env` یا ثابت‌های `server.js` رمز حسابی را که از قبل در پایگاه‌داده وجود دارد، خودکار عوض نمی‌کند. برای پایگاه‌داده قبلی، اطلاعات ورود موجود حفظ می‌شود. قبل از اولین اجرا، تنظیمات `.env` را تعیین کنید.

برای این نسخه، مقادیر پیش‌فرض حساب اولیه `admin` و `admin12345` هستند. این مقادیر را برای استفاده واقعی تغییر دهید.

## اجرای مستقیم بدون Docker

در صورت نیاز به اجرای محلی، Node.js نسخه 22.5 یا جدیدتر لازم است:

```bash
node server.js
```

در ویندوز می‌توانید از `run.bat` نیز استفاده کنید. در اجرای مستقیم، برای تغییر تنظیمات اولیه می‌توانید متغیرهای محیطی `ADMIN_USER`، `ADMIN_PASSWORD`، `HOST` و `PORT` را قبل از اجرا تعیین کنید.

## شبکه و امنیت

داخل کانتینر، برنامه روی `0.0.0.0:3000` گوش می‌دهد و پورت میزبان از طریق `APP_PORT` قابل تنظیم است. برای دسترسی از رایانه‌های دیگر در شبکه محلی، با IP رایانه میزبان و همان پورت وارد شوید و در صورت نیاز دسترسی فایروال را تنظیم کنید. برای انتشار عمومی اینترنت، HTTPS، محدودسازی دسترسی، پشتیبان‌گیری منظم و بازبینی امنیتی لازم است. `COOKIE_SECURE=false` برای اجرای محلی با HTTP تنظیم شده است؛ آن را بدون پیکربندی HTTPS معکوس به `true` تغییر ندهید.

## API نرخ ارز

برنامه از این نشانی استفاده می‌کند:

`https://api.priceto.day/v1/latest/irr/usd`

فیلد `price` به‌عنوان قیمت ریالی هر دلار تفسیر می‌شود. درخواست سمت سرور است و نرخ حداکثر هر ۵ دقیقه تازه‌سازی می‌شود. در صورت قطعی سرویس، آخرین نرخ ذخیره‌شده نمایش داده می‌شود؛ اگر هنوز نرخی ذخیره نشده باشد، برخی عملیات مالی تا دریافت نرخ متوقف می‌شوند. نرخ بازار آزاد ممکن است با نرخ معامله واقعی متفاوت باشد.

## گزارش PDF

به صفحه «گزارش‌ها» بروید، تاریخ شمسی و فیلترها را تعیین کنید و گزارش را بسازید. سپس گزینه «چاپ / ذخیره PDF» را بزنید و در پنجره چاپ مرورگر، مقصد **Save as PDF / ذخیره به‌صورت PDF** را انتخاب کنید.
